# Exhibition Invariants

- This is a tracking artwork, not a generic surveillance demo.
- One tracking action must preserve multiple possible outcomes: control, exclusion, distortion, reconstruction.
- Do not add face recognition, age/gender/race inference, or biometric identification.
- Preserve or prepare support for these outcome labels:
  - `matched`
  - `ambiguous`
  - `low_confidence`
  - `no_match`
- Do not optimize only for correct identification.
- Type A/B/C semantics and the 75-frame stability window must remain unchanged unless a future plan explicitly changes them.
